HTML SHORTCUT

Webページへの入口を、
小さなHTMLとして保存する

ブラウザのブックマークとは別に、クリックすると特定のWebページへ移動するだけの短いHTMLファイルを保存しておく仕組みです。ファイルとして置いておけるため、フォルダ管理やバックアップにも向いています。

「HTMLショートカット」という考え方

例えば、公開中のサイトに 「開くとこのサイトにアクセスできるファイルをダウンロード」 ボタンを置きます。

そのボタンを押すと、現在のページURLを記録した小さなHTMLファイルがダウンロードされます。後からそのHTMLを開くだけで、元のWebページへすぐ移動できます。

動作イメージ

公開サイトを開く

この仕組みを設置したWebページを開きます。

HTMLショートカットを保存

ボタンを押すと、遷移先URLだけを持つ小さなHTMLファイルを保存します。

後からファイルを開く

保存したHTMLをダブルクリックすると、その時点の Date.now() をクエリに付けて元のWebページへ移動します。

保存されるHTMLは非常に短い

中身は、ほぼ「このURLへ移動する」という処理だけです。開いた瞬間に Date.now() を付けることで、古いキャッシュが使われにくくなります。

<!doctype html><meta charset="utf-8"><script>location.replace("このページ自身のURL?"+Date.now())<\/script>

元サイトの内容そのものを保存するのではなく、元サイトへ戻るための入口だけを保存する仕組みです。Date.now() は保存時ではなく、ショートカットHTMLを開いた時に評価されます。

ファイルとして管理できる

フォルダに分類したり、USBメモリやクラウドストレージへ置いたりできます。

元ページが更新されても反映されやすい

HTML自体に内容をコピーせず、遷移時に毎回異なるクエリを付けるため、古いキャッシュの影響も受けにくくできます。

容量が非常に小さい

基本的にはURLと遷移処理だけなので、通常のWebページ保存よりかなり軽量です。

ブックマーク以外の保存方法になる

ブラウザ依存のブックマークとは別に、普通のファイルとして持ち運べます。

このページから試す

下のボタンを押すと、現在このページを公開しているURLへ移動するための小さなHTMLファイルを保存します。

実際の実装では、固定URLではなく location.href を使って「ボタンを押したページ自身のURL」を取得し、保存したHTMLを開いた時に ? + Date.now() を付けて遷移します。

実装例

各ページに同じボタンを置き、押されたページ自身のURLをHTMLへ埋め込み、遷移時にキャッシュ対策用の値を付ける場合は、次のような形にできます。

<button id="saveShortcut">開くとこのサイトにアクセスできるファイルをダウンロード</button>

<script>
document.getElementById("saveShortcut").addEventListener("click", () => {
  const url = location.href.split("#")[0].split("?")[0];
  const html = '<!doctype html><meta charset="utf-8"><script>location.replace(' + JSON.stringify(url + "?") + '+Date.now())<\\/script>';
  const blob = new Blob([html], { type: "text/html;charset=utf-8" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = "web-shortcut.html";
  a.click();
  URL.revokeObjectURL(a.href);
});
<\/script>

HTMLショートカットは、Webページそのものではなく「Webページへの入口」を保存する方法です。
